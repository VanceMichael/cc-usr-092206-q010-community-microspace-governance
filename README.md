# 社区微空间共治

管理社区小微空间从居民诉求、改造到长期共治运营。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括社区居民、街道工作人员、联建单位、空间运营伙伴、合作商户。

资料所依据的领域事实如下：

- 闲置空间被改造为早餐、儿童、文化和运动场景
- 部分项目通过场地换服务让收益反哺公益
- 居民参与认领、值守、报修和议事
- 开放时段、值守安排、收益反哺等运维事项经居民议事协商确定，比改造照片更决定小微空间能否长久使用
- 居民先提交诉求并参与方案协商，场地产权、安全条件、联建资源、施工验收和现行规则均可查询
- 运营后预约、志愿排班、设施报修与公益回馈在同一项目下运转
- 功能调整、临时关闭、噪声纠纷、商户退出或认领人变更时，留存此前约定并通知实际受影响者
- 个人诉求仅承办人员可见、处理进度向居民公开；街道按服务人群、使用情况、维修结果和收益去向核对项目是否仍符合最初协商结果

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
